## P0-05 · Deep links

All three types have a stable URL, confirmed in a browser run against the synthetic fixture (`data/baseline-a11y.json`):

| Type        | URL form                                    | Result                                                                                                 |
| ----------- | ------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| Contributor | `/c/<slug>`, e.g. `/c/fixture-fellowship-1` | opens screen `profile`, address stays `/c/<slug>` (resolves through `GET /api/v1/contributors/<slug>`) |
| Place       | `/p/<uuid>`                                 | opens screen `place`                                                                                   |
| Event       | `/e/<uuid>`                                 | opens screen `event`                                                                                   |
| Legacy      | `/index.html?c=<slug>`                      | rewritten to `/c/<slug>`; **`/?c=<slug>` is not a legacy form** and lands on the map                   |

Source: `src/frontend/app/routes.jsx`; server rewrites in `next.config.ts:60-71` (explicit list, never a catch-all). D10: a shared link keeps opening the full profile.

## Other things found while auditing (not part of this change)

4. The tracker's claim that production runs `streets-v2` is wrong (see `map-tiles.md`); RESUME_HERE says the same and should be corrected at the end of the run.
