## What the public API returns (what the sheet can rely on without a new route)

- `GET /api/v1/contributors?limit=100` (the directory the map loads, `store.jsx:2515`): profile fields **including `cover_photo_urls` but not `gallery_urls`** (`src/app/api/v1/contributors/route.ts:60-80`).
- `GET /api/v1/contributors/<slug>` (`[slug]/route.ts`): the same plus **`gallery_urls`**, `upcoming_events`, `past_events` (published, public, up to 100 each), `places`, and a follower count. Rate limit: the v1 gate, per IP and per slug (120 / minute per slug).
- News: the client already reads `news_posts` directly with the anon client (public SELECT policy) into `newsPosts` (`store.jsx:2606`), 200 newest.
- Events: the store already holds the public events (`/api/v1/events`, capped at 100 ordered by date ascending, RESUME C11).
