# Citizens Connect scenario coverage

Read [VISION.md](../../../apps/connect/VISION.md) and the [programme charter](MASTER.md) first. The commands below run from the repository root. Browser and native journeys need their own observations even when their fixture regressions pass.

| Scenario | Allowed end-to-end environment                                                        | How to run the journey                                                                                                                                                                                                                                                                                                 | Existing local fixture checks and limits                                                                                                                                                                             |
| -------- | ------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| CC-01    | Production guest, read-only                                                           | `python quality/connect/qa.py public --out <new-dir>` checks HTTP entry and CSS. Run both guest browser profiles for first entry, usable Map/Search/Explore, and refresh.                                                                                                                                              | `pnpm --filter citizens-connect test:e2e loading-splash.spec.ts` and `pnpm --filter citizens-connect test:e2e:base-path` cover landing and prefixed assets/routing with mock data.                                   |
| CC-02    | Production guest, read-only                                                           | Both guest browser profiles. Open the Pretoria map, zoom twice, select a visible marker and check that the title and type match the detail panel. Record whether tiles actually render.                                                                                                                                | `pnpm --filter citizens-connect test:e2e map-v2.spec.ts map-v2-levels.spec.ts` covers synthetic pin and zoom behaviour.                                                                                              |
| CC-03    | Production guest, read-only                                                           | Both guest browser profiles. Select a category and date, compare visible map and calendar results, then clear filters. Record missing calendar or date controls separately from a mismatch.                                                                                                                            | `pnpm --filter citizens-connect test:e2e map-v2-discover.spec.ts map-v2-levels.spec.ts` covers category chips and filtered discovery rows. No mapped calendar parity test.                                           |
| CC-04    | Production guest, read-only                                                           | Both guest browser profiles. Search for a visible public listing, open it, search a nonsense string and clear it. Check both the empty state and recovery.                                                                                                                                                             | `pnpm --filter citizens-connect test src/__tests__/api/search-autocomplete.test.ts src/__tests__/api/contributors-search.test.ts` covers mocked API behaviour. Full guest search and recovery remain browser checks. |
| CC-05    | Production guest, read-only                                                           | Both guest browser profiles. Open a public event or place, copy its share URL and reopen it in a fresh guest context. Compare the listing and route. Use Copy Link only.                                                                                                                                               | `pnpm --filter citizens-connect test:e2e:base-path` covers share URL construction and reopening with fixtures.                                                                                                       |
| CC-06    | Production guest, read-only                                                           | Both guest browser profiles. Use Tab, Shift+Tab, Enter and Escape where supported. Check visible focus, traversal, panel closure and recovery. In the narrow viewport also check tap reachability, clipping and overlap.                                                                                               | `pnpm --filter citizens-connect test:e2e map-v2.spec.ts map-v2-sheet-devices.spec.ts` covers synthetic pin keyboard access, sheet layout and touch-target sizes.                                                     |
| CC-07    | Verified isolated staging only                                                        | `python quality/connect/qa.py staging --out <new-dir>` checks the prerequisite and exits blocked in Phase 1. Phase 3 implements authenticated join, cancel, draft and cleanup against an independently verified staging pair.                                                                                          | `pnpm --filter citizens-connect test:e2e guest-actions.spec.ts signed-in-save-cohosts.spec.ts` covers adjacent mock guest and signed-in flows. It does not execute CC-07.                                            |
| CC-08    | Emulator and physical Android device; verified isolated endpoints for mutable actions | Phase 4. After verifying the mobile API and delivery targets, prepare the release candidate with `pnpm --filter citizens-connect cap:sync`, then use `pnpm --filter citizens-connect cap:run:android` for emulator and hardware. See the [mobile launch runbook](../../../apps/connect/docs/MOBILE_LAUNCH_RUNBOOK.md). | `pnpm --filter citizens-connect test src/__tests__/lib/capacitor/share.test.ts` is a mock bridge regression. Native readiness requires device evidence.                                                              |

The Phase 2 browser commands are `node quality/connect/guest.mjs desktop` and `node quality/connect/guest.mjs narrow`. Each opens a fresh Chromium context. Follow the rows in order, exit the first browser before starting the next, and launch a fresh context for each CC-01 repeat and for CC-05 link reopening. The launcher has a request allowlist. Check the operator notes in [README.md](../README.md) before recording a failure under this policy.
